## 8. AI Guardrail

Do not add AI before the core workflow works.

Correct order:

```txt
1. Upload
2. Schedule
3. Publish
4. Track status
5. Handle failures
6. Then add AI assistance
```

## 9. Analytics Guardrail

Do not add analytics until:

```txt
[ ] Real posts are being published.
[ ] Platform IDs are stored.
[ ] Platform account connections are stable.
[ ] API permissions for analytics are confirmed.
```

## 10. Future Evaluation

Before implementing any feature from this document, answer:

```txt
Does this help the current user publish posts more reliably?
Does it require paid API access?
Does it add platform approval complexity?
Does it require multi-user/team infrastructure?
Can it be postponed without harming MVP validation?
```
